Language learning facilities

Student’s Book Review 5 · report for the Principal (140–190 words).

Task

The school where you learn English has decided to improve its language learning facilities. You have been asked to write a report for the Principal, describing the current facilities and making suggestions for improvements. Report on the classrooms and the library and anything else you think is important.

Write your report in 140–190 words.

For more information on writing reports, see page 196 in the Student’s Book. Unit 4 has a fuller report trainer if you want extra practice: Unit 4 report.
