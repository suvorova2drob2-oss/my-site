Form

1.

One-syllable adjectives

Add -er and -est (or -r and -st if the adjective ends in -e). Double the final consonant if it is preceded by a short vowel.

cheap / cheaper / the cheapest

late / later / the latest

thin / thinner / the thinnest

2.

Multi-syllable adjectives

Use more and the most. For two-syllable adjectives ending in -y after a consonant, change -y to -i and add -er / -est.

sincere / more sincere / the most sincere

happy / happier / the happiest

3.

Two-form adjectives

Some two-syllable adjectives can take either form, e.g. clever, common, friendly, gentle, likely, narrow, pleasant, polite, quiet, simple, stupid, tired.

clever → cleverer OR more clever

4.

Adverbs

Most adverbs use more / the most (e.g. quietly / more quietly). Some short adverbs add -er / -est: fast, hard, late, long, soon.

fast / faster  ·  hard / harder  ·  long / longer

5.

Irregular forms

good / well → better → the best

bad / badly → worse → the worst

far → further / farther → the furthest / the farthest

Use

1.

Basic comparison

Use comparative + than.

For me, listening is more difficult than reading.

2.

Modifying the degree of difference

Small difference: a bit, a little, slightly + comparative.

Big difference: much, (quite) a lot, far, significantly + comparative.

3.

Emphasising superlatives

by far, easily + superlative. Use in for a specific group.

It’s by far the best book I’ve read this year.

4.

Less / least

Opposites of more / the most. Less / least with uncountable nouns; fewer / fewest with plural countable nouns.

5.

Similarities — as … as

(just) as + adjective/adverb + as. Negative: not so … as or not as … as.

With nouns: not such a + adjective + noun + as.

Quantities: as much … as (uncountable) / as many … as (countable).

6.

Similarity with nouns

be + (just / nearly / almost / not quite) the same + noun + as

Typical nouns: age, colour, height, length, size, weight, width.

7.

Double comparatives (change)

the + comparative, the + comparative

The more money I have, the faster I spend it.

8.

Differences between things

little / no / (not) a lot of / (not) a great deal of / not much difference between …

9.

Collocations

verb + more of a/an + noun

make more of an effort  ·  pose more of a danger than …
